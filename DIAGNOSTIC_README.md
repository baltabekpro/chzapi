# Диагностика сертификатов ЦРПТ

## Описание
Скрипт `certificate_diagnostic.py` предназначен для поиска сертификатов, вызывающих ошибку "Текущий пользователь не принадлежит выбранной товарной группе" при создании задач нарушений в системе ЦРПТ.

## Требования
- Python 3.6+
- Библиотеки: `requests`, `pyjwt`
- Файл `true_api_tokens.json` с токенами сертификатов

## Установка зависимостей
```bash
pip install requests pyjwt
```

## Использование

### Запуск скрипта
```bash
python certificate_diagnostic.py
```

### Режимы работы

#### 1. Безопасный анализ (рекомендуется)
- Анализирует только JWT токены
- Не выполняет API запросы
- Создает прогнозы возможных ошибок
- Результаты: `safe_analysis_summary.json`, `safe_analysis_predictions.csv`

#### 2. Полная диагностика
- Выполняет реальные API запросы
- **ВНИМАНИЕ:** Создает задачи в системе ЦРПТ!
- Тестирует все комбинации сертификат+товарная группа
- Результаты: `full_diagnostic_summary.json`, `full_diagnostic_report.csv`

## Файлы результатов

### safe_analysis_summary.json
Полный отчет безопасного анализа с информацией о токенах и прогнозами.

### safe_analysis_predictions.csv
CSV файл с прогнозами для каждой комбинации сертификат+товарная группа.

### full_diagnostic_summary.json
Результаты полной диагностики с реальными API тестами.

### full_diagnostic_report.csv
Подробный CSV отчет всех API тестов для анализа в Excel.

## Интерпретация результатов

### Статусы в токенах:
- `ACTIVE` - группа активна, должна работать
- `INACTIVE` - группа неактивна, возможны ошибки
- `NOT_FOUND` - группа отсутствует в токене

### Прогнозы:
- `SUCCESS` - ожидается успешное выполнение
- `FAIL_INACTIVE` - ошибка из-за неактивной группы
- `FAIL_NO_ACCESS` - ошибка из-за отсутствия доступа

## Рекомендации

1. **Начните с безопасного анализа** для выявления потенциальных проблем
2. **Изучите CSV файлы** в Excel для удобного анализа
3. **Используйте полную диагностику осторожно** - она создает реальные задачи
4. **Обратитесь к администратору ЦРПТ** для восстановления прав проблемных сертификатов

## Поддержка
Скрипт создан для автоматизации процесса поиска проблемных сертификатов в системе ЦРПТ.
